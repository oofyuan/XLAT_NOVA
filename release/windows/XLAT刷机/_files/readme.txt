XLAT 一键刷机（Windows 10/11）

【安装版：XLAT一键刷机-安装.exe】
1. 双击安装包，按提示完成安装。
2. 安装过程中会自动安装 ST-LINK 官方驱动，并可能弹出一次管理员授权，请点“是”。
3. 用 mini-USB 线把 XLAT / STM32F746G-DISCO 连到电脑，确认板子电源灯亮。
4. 双击桌面上的“XLAT一键刷机”，按提示确认即可刷机。

【绿色版：XLAT-flash-Windows-portable.zip】
1. 解压整个压缩包，不要只解压单个文件。
2. 如果电脑是第一次使用，先双击上一级目录里的“1-Install-Driver.bat”，按提示完成 ST-LINK 驱动安装。
3. 用 mini-USB 线把板子连到电脑，确认电源灯亮。
4. 双击上一级目录里的“2-Flash-XLAT.exe”，按提示确认即可刷机。
   如果软件提示未检测到设备，可以直接选“是”，让它自动安装驱动；
   安装后重新插拔一次 USB 再运行。

【刷机成功之后】
- 重新插拔一次板子电源，屏幕默认进入英文界面。
- 如需中文，请进入 Settings -> Language，选择 CN；设置会自动保存，下次开机仍保留。
- 刷机期间请勿断开 USB。

【失败怎么办】
- 先检查 USB 线、板子电源灯。
- 重新插拔 USB 后，再运行一次。
- 打开同目录下的 flash.log 查看具体报错。
- 驱动已包含在本包中，不需要再去官网下载。

【卸载 ST-LINK 驱动】
- 右键上一级目录里的“3-Uninstall-Driver.bat”，选择“以管理员身份运行”。
- 脚本会彻底卸载 ST-LINK 驱动：删除设备节点、驱动包、芯片配置文件，并清除
  所有相关注册表记录，还原到未安装前的状态。
- 注意：彻底卸载后重新插入设备，Windows Update 可能会自动下载安装驱动，
  这与全新系统首次插入的行为一致。如需重新安装本工具自带驱动，运行
  “1-Install-Driver.bat”即可。
- 卸载后如需重新安装，运行“1-Install-Driver.bat”即可（会自动解除阻止）。

【目录说明】
- 上一级目录只保留三个常用程序，请按 1 -> 2 的顺序操作。
- 本目录 `_files` 是刷机工具的运行依赖，请保持整个文件夹完整，不要删除或移动里面的文件。
